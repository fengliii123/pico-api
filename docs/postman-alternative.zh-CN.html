从 Postman 或 ApiFox 迁移

  • cURL 粘贴导入:任何 cURL 命令直接粘贴即还原为可编辑请求,也可以先用在线 cURL 转换工具预览解析结果
  • OpenAPI / Swagger:规范文件整包导入,自动生成树状集合
  • ApiFox 项目:导出的项目文件可直接导入;Postman 收藏集可先导出为 OpenAPI 再导入
  • 脚本兼容:前置/后置脚本使用 Postman 风格的 pm.* API,pm.test 断言、环境变量读写写法一致,迁移成本低

什么情况选哪个

  • 选 Pico API:日常调自己或团队的接口、在意数据不上云、希望打开即用像开个标签页一样快。
  • 选 Postman:团队需要云端共享集合,或依赖 Mock 服务、监控、API 治理这类平台能力。
  • 两个都用:很多开发者的做法是——重型客户端留给团队协作,轻量的留给日常快速验证,Pico API 就是那个轻量的。

常见问题

Pico API 是免费的 Postman 替代品吗?

是。Pico API 全功能免费——请求构造、环境变量、脚本测试、导入导出全部包含。没有账号、没有团队套餐,也不存在需要付费的云同步。

支持 Postman 的脚本和断言吗?

支持。前置/后置脚本采用 Postman 风格的 pm.* API,包括 pm.test 断言、pm.environment、pm.globals 和 pm.variables,从 Postman 迁移脚本几乎不用改。

能导入 Postman、ApiFox 或 cURL 的数据吗?

可以。粘贴任意 cURL 命令即可还原请求;OpenAPI/Swagger 规范和 ApiFox 项目可整项目导入为集合。Postman 收藏集可先导出为 OpenAPI 再导入。

我的数据存在哪里?安全吗?

集合、环境、历史全部通过浏览器 IndexedDB 存在本地,不上传任何服务器。无统计埋点、无广告、无第三方脚本,详见隐私政策。
