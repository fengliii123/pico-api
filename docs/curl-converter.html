cURL to HTTP Request Converter

Paste a cURL command — see the parsed HTTP request (method, URL, headers, auth, body) instantly. Everything runs in your browser; nothing is uploaded anywhere.

Install Pico API — Free

Want to actually send this request? Install Pico API (free, no account) — it imports pasted cURL commands directly (Import → cURL), with environments, scripts, and a response viewer.

What this tool parses

  • Request method: -X / --request (inferred as POST when -d is present)
  • Headers: -H / --header (repeatable)
  • Body: -d / --data / --data-raw / --data-binary
  • Basic auth: -u / --user
  • Single-quoted, double-quoted, and unquoted arguments, plus \ line continuations

Why convert cURL to a request?

  • Debug a cURL command someone pasted into a bug report or docs page
  • Read what a copy-as-cURL from browser DevTools actually sends
  • Move a one-off terminal request into a saved, editable collection
